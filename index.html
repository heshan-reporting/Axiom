Settings
Everything runs on open public data through your Cloudflare worker. The Claude key powers the Analyst and Briefings.
The API key stays in this browser's localStorage and is sent only to api.anthropic.com. The worker URL is pre-configured — change it only if you deploy your own.
Comms & ClickUp
The Gemini key stays in this browser and is sent only to generativelanguage.googleapis.com. Get one free at aistudio.google.com/apikey. If Gemini fails, AXIOM falls back to Claude for the posts.
Your ClickUp token lives only on the worker as a secret (CLICKUP_TOKEN) — never in the browser. Set it with wrangler secret put CLICKUP_TOKEN. The List ID above is safe to store here.
WhatsApp news alerts
For hot news, push the alert + brief straight to WhatsApp from Content Studio. Numbers are safe to store here; the WhatsApp token lives only on the worker — Meta Cloud API (WA_TOKEN+WA_PHONE_ID) or Twilio (TWILIO_SID/TWILIO_AUTH/TWILIO_WA_FROM). Note: outside the 24-hour window Meta requires a pre-approved template.
Image visuals use Google's gemini-3-pro-image ("Nano Banana Pro" — strongest text rendering and multi-turn editing) via the Gemini key on the worker (GEMINI_KEY), with automatic fallback to gemini-3.1-flash-image / gemini-2.5-flash-image if unavailable.
