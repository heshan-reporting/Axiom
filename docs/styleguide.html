AXIOM · Design System · v1

Graphite & Signal

One navy-graphite base. One azure signal accent. Semantic colour only where it means something. Bricolage Grotesque for display, Instrument Sans for the interface, Spline Sans Mono for data. Every distance, radius, shadow and movement comes from the tokens on this page.
